## 搬瓦工香港 CN2 GIA 的线路到底好在哪

香港 CN2 GIA 机房（HKHK_8）位于香港 MEGA2 数据中心，是搬瓦工全线产品里延迟最低、线路最好的机房。三网直连的具体结构是：电信走双向 CN2 GIA（AS4809），联通去程直连、回程也已接入 CN2 GIA，移动走 CMI 线路，端口带宽 1Gbps。

延迟数据比营销话术有说服力。根据多个测评站的实测汇总：广东/广州电信约 8–15ms，上海电信约 28–40ms，北京电信约 40–55ms，移动和联通全国普遍在 30–60ms。另一组更早的分区域测试也印证了这个水平：电信平均 42.2ms、华南 28.3ms、港澳台 16.8ms，广州天翼云节点测到过 8.8ms。CN2 GIA 线路的丢包率长期接近 0%，而普通 IP transit 通道在峰值时段丢包率可能达到 30% 以上——这就是晚高峰差距的来源。

速度方面，1Gbps 端口实测基本可以跑到 500Mbps，三网方向晚高峰表现稳定。
